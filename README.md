# 발송 대상 및 메시지 DB 운영 자동화

> 이 저장소는 실제 인턴 및 별도 프로젝트 경험을 설명하기 위해 새로 작성한 공개 포트폴리오입니다. 회사의 원본 소스, 데이터베이스, 고객 정보, 운영 설정, 인증정보를 포함하지 않습니다. demo.py와 예시 데이터는 2026년에 처음부터 작성한 독립적인 오프라인 재현 예제로, 2024년 실제 운영 코드를 복제하거나 당시 배포 사실을 증명하지 않습니다.

**기간:** 인턴: 2024.07~09  
**실제 업무 기술:** Python, MySQL, pandas, Excel, SQL 백업

## 배경과 해결하려던 문제

업무 대상과 메시지 데이터를 여러 파일에서 수정하고 중복 또는 응답 완료 대상을 관리하는 작업이 반복됐습니다.

## 직접 수행한 작업

- 대상 목록 추가, 회신 대상 제외, 메시지 수정에 필요한 Python 및 SQL 스크립트를 작성했습니다.
- 데이터를 변경하기 전 테이블 백업을 수행하는 절차를 구성했습니다.
- 반복적인 DB 정리 및 발송 목록 준비 작업을 자동화했습니다.
- 원본 업무 흐름을 설명하는 운영 매뉴얼을 작성했습니다.

## 기여 범위 및 사실 확인

실제 회사 MySQL 스키마, 접속정보, 백업, 고객 목록은 공개하지 않습니다. 데모는 외부 의존 없이 실행 가능한 SQLite 가상 모델이며 실제 DB 스키마와 다릅니다.

## 공개 오프라인 데모

가상 대상의 중복 등록과 응답 대상 제외, 트랜잭션 처리 및 남은 대상 조회를 SQLite로 구현합니다.

```bash
python demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상을 권장합니다. 외부 API 키나 실서비스 계정이 필요하지 않습니다.

## 실행 가능한 트랜잭션 및 백업 데모

`operations.py`는 가상 데이터를 기반으로 트랜잭션 입력과 롤백, 중복 제거, 응답 완료 대상 제외, 메시지 수정 및 SQLite 백업을 구현합니다. 2024년의 MySQL 원본 코드와 스키마는 사용하지 않았습니다.

```bash
python operations.py
python -m unittest discover -s tests -v
```
