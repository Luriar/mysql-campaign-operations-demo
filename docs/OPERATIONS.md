# 가상 캠페인 DB 운영 예제

실무에서 다뤘던 고객 후보 데이터 추가와 제외, 메시지 내용 관리, DB 백업을 설명하기 위한 신규 구현입니다. 실제 회사 MySQL 구조 및 운영 정책과는 다르며, SQLite를 사용해 외부 의존성을 없앴습니다.

진행 순서: 가상 대상 검증 → 트랜잭션 기반 입력 → 응답 완료 대상 표시 → 발송 대기 대상 조회 → 변경 이력 → SQLite 파일 백업.

- 입력에 오류가 있으면 앞서 처리한 레코드도 함께 롤백합니다.
- 같은 코드가 반복 입력되어도 중복 행을 만들지 않습니다.
- 답변 완료 상태는 대상 정보를 재입력해도 유지됩니다.
- 백업 파일에서 결과를 복원해 테스트할 수 있습니다.
- 실제 사용자 연락처, 서버 비밀번호, 내부 SQL 원본은 없습니다.

실행: python operations.py
테스트: python -m unittest discover -s tests -v
